# 드림그룹 다음 개선 백로그

작성일: 2026-08-08

기준 빌드: standalone RC 후보

목표: 최애돌 유저에게 `최애 애착 → 반복 육성 → 수집 → 팬덤 약속 → D1 복귀 → 첫 그룹`을 만드는 상용 리텐션 게임

## 패널 결론

현재 첫 RUN은 판매력이 있다. 모바일 UX 전문가는 리텐션 후보를 **7.4/10**으로 평가했고, 세 팬 페르소나는 D1 복귀 의향을 각각 **9/10, 8/10, 8/10**으로 추정했다. 가장 강한 장면은 실제 최애·팬덤 이름이 들어간 첫 약속이고, 가장 큰 제품 이탈 후보는 첫 결과에서 두 번째 멤버와 첫 그룹의 완성 가치를 충분히 미리 보여주지 못하는 점이다.

단, 상용 공개는 재미와 별개로 권리·공개 처리방침·관측성·롤백 증빙이 없어 아직 NO-GO다. 스탠드얼론 빌드의 공용 Firebase 직접 접근은 이번 배치에서 제거했고, 개인 차트와 고스트 리그는 이 기기 안에서만 작동한다.

## 우선순위 10개

### P0 — 외부 사용자에게 내기 전

1. **권리·개인정보 상용 증빙 완료**
   - 아이돌 이름·사진, 배경·마스코트·폰트·음원·효과음의 이용 범위를 빌드에 연결하고 공개 개인정보 처리방침 URL을 확정한다.
   - 완료 기준: `node tools/release-gate.mjs --production`에서 권리와 처리방침 항목이 실제 승인 문서 경로와 함께 PASS.

2. **재현 가능한 배포와 롤백 게이트**
   - main push 즉시 배포 대신 테스트·브라우저 스모크·릴리즈 게이트를 통과한 고정 SHA만 배포한다.
   - 완료 기준: 테스트 실패·dirty 런타임은 배포 불가, 출시 SHA와 마지막 정상 SHA 기록, 제한 시간 안 롤백 훈련 통과.

3. **텔레메트리 종단 완성**
   - 동의 이후 이벤트를 받는 실제 수집기, `event_id` 멱등 처리, ACK, 보유기간, 장애 경보와 담당자를 연결한다.
   - 완료 기준: 동의 전 0건, 거부 시 ID·outbox 삭제, 오프라인 재전송 후 이벤트당 적재 1건, 테스트 장애가 담당자에게 경보.

4. **저장·복구·저사양/불안정망 실기기 검증**
   - Android Chrome/WebView와 iPhone Safari에서 용량 부족, JSON 손상, 강제 종료, 백그라운드, 재접속을 검증하고 내보낸 저장의 가져오기 정책을 결정한다.
   - 완료 기준: 정확한 턴 복구, `run_id` 중복 보상 0건, 복구 상태 가시화, 지원한다면 export→reset→import 동일 상태 복원.

### P1 — 리텐션 임팩트가 큰 제품 개선

5. **첫 결과에 3인 그룹 완성 미리보기**
   - `현재 1/3 → 다음 멤버가 물려받는 멘토·지원 → 3/3 첫 리허설`을 한 장의 실루엣 진행판으로 보여준다. 주 CTA는 하나만 둔다.
   - 완료 기준: 5인 비게이머 테스트에서 첫 결과 직후 “왜 두 번째 멤버를 키우는지” 4명 이상이 도움 없이 설명하고 두 번째 RUN 시작률 개선.

6. **두 번째 RUN을 계승 데모로 차별화**
   - 이전 최애 카드의 얼굴·완주 기록 한 가지가 새 멤버의 첫 손패에 어떻게 이어지는지 시작 전과 첫 턴에 즉시 보여준다.
   - 완료 기준: 반복 복제로 인식한 사용자 비율 감소, 첫 턴에 계승 효과 인지 80% 이상, 기존 자동 장착 계약 유지.

7. **첫 3분 HUD 단계적 공개**
   - 첫 턴은 추천 이유·획득량·기력·다음 관문을 중심으로 두고, 멘탈·유대·세부 6영역은 관련 사건에서 강조해 등장시킨다. 숙련 정보는 접어 보존한다.
   - 완료 기준: 초보가 추천 이유와 다음 행동을 10초 안에 설명, 숙련자는 예상 범위와 위험 정보를 한 번의 탭으로 확인.

8. **글로벌 진입과 D1 시간의 현지화**
   - 앱/브라우저 언어 자동 감지 결과를 첫 화면에서 확인·변경하게 하고, KST 고정 답장을 현지 시각 또는 정확한 카운트다운으로 표현한다.
   - 완료 기준: ko/en/ja/id 신규 origin이 올바른 언어로 시작, 현지 사용자가 답장 도착 시각을 오해하지 않음.

9. **신규 홈 보상 소음 제거**
   - 첫 진입의 업적 2개·보상 도착 알림을 첫 RUN CTA 이후로 지연하거나 하나의 축약 알림으로 합친다.
   - 완료 기준: 최초 화면에서 시스템 알림이 최애 선택 CTA를 덮지 않고, 업적 보상은 소실 없이 첫 RUN 뒤 회수 가능.

10. **모바일·언어·성능 캡처 매트릭스 자동화**
    - 360×800, 390×844, 412×915 × ko/en/ja/id에서 선택 도크, RUN, Daily, 결과 D1, 편성, 고스트 리그를 실제 캡처하고 저사양 WebView 성능 예산을 건다.
    - 완료 기준: 잘림·겹침·44px 미만 핵심 타깃·미번역 0건, 대표 저사양 기기의 합의된 LCP·메모리·전송량 예산 통과.

## 다음 배치 권고

한 번에 열 개를 모두 만들지 않는다. 다음 배치는 `P0-1~4`의 출시 기반과 `P1-5`의 그룹 미리보기까지만 묶는다. 검증은 구현 항목을 모두 끝낸 뒤 자동 회귀 → 세 팬 페르소나 → UX·엔지니어 → 까칠이 순으로 한 번만 실행한다. 이후 수치와 관찰 결과로 6~10의 순서를 다시 정한다.
