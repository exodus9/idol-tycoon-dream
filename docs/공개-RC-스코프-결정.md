# 드림그룹 공개 RC 스코프 결정

결정일: 2026-08-08

## 결정

이번 GitHub Pages 배포는 최애돌이 운영하는 드림그룹 공개 RC다. 제품 책임자 지시에 따라 아이돌 IP, 최애돌 기존 개인정보 정책, 배경·폰트·음원 등 번들 자산의 조직 차원 검토는 이 코드 배포의 선행조건에서 제외한다.

이는 해당 권리나 정책이 불필요하다는 법률 판단이 아니다. 현재 RC에서 별도 코드 산출물로 중복 증빙하지 않는다는 제품 범위 결정이다.

## 유지하는 안전 조건

- 분석 이벤트는 사용자가 허용한 이후에만 생성한다.
- 거부하면 분석 식별자와 전송 대기열을 삭제한다.
- 진행 데이터는 내보내기와 완전 초기화를 제공한다.
- 개인 차트와 고스트 리그는 기기 로컬 전용이며 공용 Firebase를 읽거나 쓰지 않는다.
- 공개 배포 전 전체 회귀, 정적 검사, `public_rc` 게이트를 CI에서 통과해야 한다.

## 정식 상용 운영에서 별도로 남는 것

운영 관측성, 롤백 훈련, 최애돌 계정 귀속 서버 원장과 서버 권한 경쟁 판정은 정식 앱인앱 통합·상용 운영 단계의 별도 게이트다.
