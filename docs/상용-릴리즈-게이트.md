# 드림그룹 상용 릴리즈 게이트

현재 빌드는 **로컬·접근 통제된 내부 플레이용 RC는 가능하지만 공개 URL과 상용 출시는 NO-GO**다. GitHub Pages처럼 누구나 접근하는 주소는 이름이 RC여도 공개 배포이므로 권리와 개인정보 게이트를 우회할 수 없다. 게임 코드의 완성도와 별개로, 증빙 없는 권리·개인정보·운영 안전을 추정으로 통과시키지 않는다. 최애돌 실섭 연동은 이 문서의 마지막 범위이며 현재 스탠드얼론 합격과 분리한다.

## 자동 판정

- 내부 RC: `node tools/release-gate.mjs`
- 공개 RC/프리뷰: `node tools/release-gate.mjs --public`
- 상용 공개: `node tools/release-gate.mjs --production`
- 판정 원장: `release-gate.json`

`pass`에는 반드시 저장소 안에 실제 존재하는 검증 증거가 붙어야 한다. `unverified`는 실패가 아니라 담당 조직의 증빙이 아직 이 빌드에 결합되지 않았다는 뜻이지만, 공개 RC와 상용 공개에는 차단 조건이다.

## 현재 차단 항목

1. `idols.js`의 실존 아이돌 이름과 CDN 사진을 이 게임에서 상업 이용할 수 있다는 승인 범위가 저장소에 없다.
2. 배경·마스코트·폰트·음원·효과음의 파일별 출처와 라이선스 원장이 없다.
3. 게임 내 설명은 생겼지만, 운영 주체·문의·보유기간을 포함한 승인된 공개 개인정보 처리방침 URL이 없다.
4. 런타임 오류 이벤트는 생성하지만 실제 수집 엔드포인트, 경보, 온콜 담당과 장애 훈련 증거가 없다.
5. 배포 버전과 마지막 정상 버전을 특정해 되돌린 실전 롤백 기록이 없다.

## 증빙이 들어오면 바꾸는 법

각 담당자는 `release-gate.json`의 해당 항목에 문서나 자동 테스트 경로를 `evidence`로 연결하고 `status`를 `pass`로 바꾼다. 파일명만 적지 말고 승인 범위·대상 빌드·유효 기간이 실제로 확인되는 자료여야 한다. 그 뒤 전체 테스트와 `--production` 판정을 다시 실행하고, 출시 SHA를 고정한다.

## 최애돌 연동 시 추가 게이트

SSO 토큰 검증, 계정 귀속 저장 원장, 서버 권한 보상·시즌 판정, 네이티브 분석 동의 전달, 원격 킬스위치는 별도 R3 게이트다. 현재 로컬 저장이나 고스트 리그를 그 기능처럼 소개하지 않는다.
