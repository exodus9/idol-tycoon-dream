# 드림그룹 릴리즈·롤백 런북

배포물은 저장소 전체가 아니라 `tools/build-release.mjs`가 만든 `_site`만 사용한다. `_site/release.json`은 소스 SHA와 공개 파일별 SHA-256을 기록한다.

## 정상 배포 확인

1. GitHub Pages 워크플로의 verify와 deploy가 모두 성공했는지 확인한다.
2. 실 URL의 `/release.json`에서 `sha`가 배포 커밋과 같은지 확인한다.
3. 390×844에서 신규 진입→최애 선택→첫 카드 선택, 기존 저장→홈, 저장 내보내기까지 스모크한다.

## 롤백

`node tools/rollback-plan.mjs <last-known-good-sha>`로 대상 커밋 존재 여부와 실행 명령을 먼저 검증한다. 현재 main의 검증된 패키징 도구가 지정 SHA의 런타임만 별도 worktree에서 묶으므로, 과거 커밋에 manifest 도구가 없어도 `release.json.sha`를 목표 SHA로 만들 수 있다. 출력된 워크플로 실행은 운영 담당자가 대상 SHA를 재확인한 뒤 수행한다. 완료 기준은 워크플로 성공만이 아니라 실 URL의 `release.json.sha` 일치와 모바일 스모크 통과다.

이 스크립트는 기본적으로 아무 것도 변경하지 않는 드라이런이다. 원격 변경은 출력된 명령을 사람이 명시적으로 실행할 때만 발생한다.
